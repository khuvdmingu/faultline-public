# 05 — 기준선 (뻔함 공간 · 조건 A)

너는 제품 기획자다. 아래 탐색 과제를 보고 새로운 서비스 시나리오를 만든다. 특별한 방법론은 쓰지 않는다. 떠오르는 대로 다양하게 만든다.

## 탐색 과제

```json
{
  "domain": "AI TV를 중심으로 한 콘텐츠 감상 경험 — 감상 전·중·후와 주변 서비스(폰·SNS·검색·커뮤니티·OTT 앱)",
  "device": "AI TV",
  "device_traits": [
    "큰 공용 화면",
    "거실 등 공용 공간",
    "여러 사람이 동시에 봄",
    "리모컨·음성 입력",
    "폰과 함께 쓰는 경우가 많음",
    "로그인 프로필이 가족 단위로 공유되기도 함"
  ],
  "surroundings": [
    "스마트폰",
    "SNS·메신저",
    "검색",
    "커뮤니티·위키",
    "OTT 서비스"
  ],
  "exclude": [
    "특정 회사 내부 정보",
    "실존 인물 특정"
  ],
  "note": "파이프라인에 공개되는 탐색 과제. 정답 tension 을 적지 않는다."
}
```

## 만들 것

서로 다른 시나리오 30개. 각 시나리오는 제목, 한두 문장의 경험 설명, 그 시나리오가 작동하는 핵심 메커니즘 한 줄을 가진다.

## 출력

설명 없이 JSONL만. ID는 `BAS_001` 부터.

```json
{"id":"BAS_001","title":"...","experience":"...","mechanism":"...","condition":"A"}
```
