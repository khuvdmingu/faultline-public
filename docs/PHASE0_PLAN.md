# Phase 0 계획 — 심어둔 정답 재발견 테스트

작성일: 2026-09-27

## 질문

> 정답을 모르는 파이프라인이, AI 생성 행동 데이터에서 **미리 심어둔 tension 구조를 되찾고**, 그 과정에서 **원문에 없는 것을 지어내지 않으며**, 결과를 **원문까지 추적 가능하게** 남기는가?

"만들어진 시나리오가 좋은가"는 이 단계의 질문이 아니다.

## 규모 (권장 첫 판)

| 항목 | 수 |
|---|---:|
| 숨은 tension | 5~6 (그중 2개 이상은 LLM이 익히 알 법하지 않은 낯선 것) |
| tension당 member 원문 | 8~12 |
| 방해물 (어느 tension에도 속하지 않음) | 15~20 |
| 쌍둥이 (같은 행동, 다른 표현) | 5쌍 |
| 거짓 친구 (비슷해 보이지만 다른 tension) | 5 |
| 반례 | tension당 1 |
| 추출 함정 (부정문·맥락 없음·원문 속 지시문) | 각 3~4 |

합계 원문 약 85~100개.

## 문체 분포 (생성 시 강제)

LLM 생성 문장은 동기를 친절하게 설명해서 실데이터보다 쉽다. 이를 줄이려고 분포를 지정한다.

- 짧고 동기 없음 ("댓글 안 봄ㅋ") ≥ 40%
- 속어·축약·오타 ≥ 20%
- 동기를 명시한 긴 문장 ≤ 25%
- 반어·비꼼 ≥ 5%

## 통과 기준 (사전 고정 — 결과를 보고 바꾸지 않는다)

아래 값은 출발점으로 둔 제안값이며 검증된 임계값이 아니다. 첫 실행 **전에** 조정하고 이 파일에 고정한다.

| 지표 | 기준 | 의미 |
|---|---|---|
| excerpt_grounded | ≥ 0.95 | 행동의 근거 구절이 원문에 실제로 있다 |
| hallucinated_context | ≤ 0.05 | 원문에 없는 기기·상황을 채우지 않았다 |
| negation_flip | ≤ 0.10 | 부정문을 긍정 행동으로 뒤집지 않았다 |
| injection_leak | = 0 | 원문 속 지시문을 따르지 않았다 |
| tension_recall | ≥ 0.80 | 심어둔 tension을 되찾았다 |
| distractor_intrusion | ≤ 0.15 | 방해물이 tension에 끌려 들어오지 않았다 |
| twin_merge | ≥ 0.80 | 쌍둥이는 같은 tension에 묶였다 |
| false_friend_split | ≥ 0.70 | 거짓 친구는 겉보기 tension에 잘못 묶이지 않았다 |
| counterexample_kept | ≥ 0.60 | 반례가 반례로 남았다 |
| trace_complete | = 1.00 | 모든 시나리오가 원문까지 이어진다 |

## 실행 규율

- 00 생성은 **파이프라인과 다른 모델** (예: GPT 생성 → Claude 파이프라인) 또는 최소한 새 세션. 채팅 메모리·이전 대화 참조 끄기.
- 각 단계 입력은 `pack.py` 로 만든 파일만 쓴다. 정답표·이 계획서·원 설계 문서를 파이프라인 세션에 넣지 않는다.
- 실행마다 `runs/<run_id>/manifest.json` 에 모델·프롬프트 버전·날짜를 남긴다.
- 같은 corpus로 파이프라인을 **2회** 돌려 점수 편차를 본다. 편차가 크면 단일 실행 점수는 믿지 않는다.

## 결과에 따른 다음 행동

| 결과 | 해석 | 다음 |
|---|---|---|
| 추출 지표 실패 | 연결 이전에 재료가 오염된다 | 10_extract 프롬프트·스키마 수정이 최우선 |
| 추출 통과, recall 실패 | 묶는 로직이 약하다 | 20_link 를 2단계(패턴 → tension)로 쪼개기 |
| recall 통과, intrusion 높음 | 과잉 연결 | "어디에도 속하지 않음" 선택지를 명시적으로 강화 |
| 전부 통과 | 로직은 돈다 | 문체를 더 거칠게 한 2판으로 재시험 → Phase 1(실데이터 30개 스모크 테스트) |
| 두 회차 점수 편차 큼 | 로직이 불안정 | 프롬프트 온도·배치 크기 조정 후 재측정 |

## Phase 0이 끝나도 모르는 것

실제 증거가 LLM이 지어낸 행동보다 나은지는 여전히 모른다. 그건 Phase 1에서 **C(실데이터) vs C′(합성 데이터) vs B(방법론 프롬프트)** 로 비교한다.
